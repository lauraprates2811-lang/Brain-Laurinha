## 1. Revisão: a estrutura da palavra

Toda palavra pode ser desmontada em **morfemas**, as menores partes que têm significado. Saber o nome
de cada peça é o que permite, depois, dizer *como* a palavra foi formada.

| Morfema | O que é | Exemplo |
|---|---|---|
| **Radical** | A parte que carrega o sentido básico e se repete em toda a família de palavras | **terr**a, **terr**eno, en**terr**ar |
| **Prefixo** | Afixo que vem antes do radical | **des**leal, **re**fazer, **in**feliz |
| **Sufixo** | Afixo que vem depois do radical | leal**dade**, feliz**mente**, pedr**eiro** |
| **Vogal temática** | Liga o radical às desinências. Nos nomes, é o -a, -e ou -o átono final que não indica gênero. Nos verbos, indica a conjugação | cas**a**, dent**e**; cant**a**r (1ª), vend**e**r (2ª), part**i**r (3ª) |
| **Tema** | Radical + vogal temática: a base pronta para receber as desinências | **canta**-, **vende**-, **parti**- |
| **Desinência nominal** | Marca gênero e número | menin**a**, menino**s** |
| **Desinência verbal** | Marca modo e tempo (modo-temporal) e número e pessoa (número-pessoal) | estud-á-**va**-**mos** |
| **Vogal ou consoante de ligação** | Entra só para facilitar a pronúncia; não tem sentido | gás**o**metro, café**t**eira, pau**l**ada |

> [!info] Vogal temática × desinência de gênero
> Se trocar a vogal muda o sexo do ser, é desinência de gênero (menin**o** / menin**a**). Se a troca
> produz outra palavra, é vogal temática (port**o** e port**a** são coisas diferentes, não o masculino e
> o feminino um do outro).

Com essas peças, a língua forma palavras novas por dois grandes processos: a **composição**, que junta
dois ou mais radicais, e a **derivação**, que parte de uma palavra só.

## 2. Composição

> [!abstract] Definição
> **Composição** é a formação de uma palavra nova pela união de **dois ou mais radicais**. O resultado
> ganha um sentido próprio, que nem sempre é a soma das partes: um *cachorro-quente* não é um cachorro.

### 2.1 Justaposição

Os radicais se juntam **sem perder nenhum som**. Cada parte continua inteira, com ou sem hífen.

- girassol (gira + sol), passatempo (passa + tempo), pontapé (ponta + pé)
- guarda-chuva, beija-flor, segunda-feira

O hífen não decide nada: *girassol* e *guarda-chuva* são os dois justapostos.

### 2.2 Aglutinação

Os radicais se **fundem** e pelo menos um deles **perde algum som** (uma letra, uma sílaba, um acento).
A palavra nova fica com uma única sílaba tônica.

| Palavra | Partes | O que se perdeu |
|---|---|---|
| planalto | plano + alto | o -o de *plano* |
| aguardente | água + ardente | o -a de *água* |
| pernalta | perna + alta | o -a de *perna* |
| vinagre | vinho + acre | o -ho de *vinho* |
| fidalgo | filho + de + algo | a expressão inteira encolheu |
| embora | em + boa + hora | a expressão inteira encolheu |

> [!info] Teste rápido
> Separe a palavra nas partes originais. Se todas voltam inteiras, é justaposição. Se alguma precisa de
> uma letra que sumiu, é aglutinação.

### 2.3 Composição erudita

Formada com radicais do **grego** ou do **latim** clássicos, **da mesma língua**. É o jeito de criar
termos científicos e técnicos. Por isso muitos desses radicais não existem sozinhos em português
(*demo*, *logia*, *crono*).

| Palavra | Radicais | Sentido ao pé da letra |
|---|---|---|
| democracia | demo (povo) + cracia (poder) | governo do povo |
| filosofia | filo (amigo) + sofia (sabedoria) | amor à sabedoria |
| biologia | bio (vida) + logia (estudo) | estudo da vida |
| geografia | geo (terra) + grafia (escrita, descrição) | descrição da terra |
| cronômetro | crono (tempo) + metro (medida) | medidor do tempo |
| antropologia | antropo (homem) + logia (estudo) | estudo do ser humano |
| agricultura *(latim)* | agri (campo) + cultura (cultivo) | cultivo do campo |
| piscicultura *(latim)* | pisci (peixe) + cultura (cultivo) | criação de peixes |
| homicida *(latim)* | homi (homem) + cida (que mata) | quem mata um homem |

> *helio* (`2025.1-DIS-LP3`). Saber o sentido do radical já responde a questão. A lista de radicais está
> nos flashcards de `formacao-de-palavras-e-efeitos-de-sentido.md`.

### 2.4 Hibridismo (composição híbrida)

Radicais de **línguas diferentes** na mesma palavra.

| Palavra | Partes e origem |
|---|---|
| automóvel | auto (grego: por si mesmo) + móvel (latim: que se move) |
| televisão | tele (grego: longe) + visão (latim: ver) |
| sociologia | socio (latim: sócio, sociedade) + logia (grego: estudo) |
| burocracia | buro (francês *bureau*: escritório) + cracia (grego: poder) |
| sambódromo | samba (de origem africana) + dromo (grego: pista, corrida) |
| alcoolômetro | álcool (árabe) + metro (grego: medida) |
| bígamo | bi (latim: dois) + gamo (grego: casamento) |
| monocultura | mono (grego: um só) + cultura (latim: cultivo) |

> [!info] A troca que a alternativa errada faz
> *Democracia* não é híbrida: *demo* e *cracia* são gregos. *Sociologia* é: *socio* vem do latim. Decore
> esse par.

## 3. Derivação

> [!abstract] Definição
> **Derivação** é a formação de uma palavra nova (a **derivada**) a partir de **uma única** palavra que
> já existe (a **primitiva**): acrescentando afixos, tirando uma parte dela ou só mudando a sua classe
> gramatical.

| Tipo | O que acontece | Exemplo |
|---|---|---|
| Prefixal | Entra um prefixo | **re**fazer, **des**leal, **des**nome |
| Sufixal | Entra um sufixo | leal**dade**, pedr**eiro**, perfum**ar** |
| Prefixal e sufixal | Entram os dois, mas **um de cada vez**: a palavra existe com só um deles | **des**leal**dade** |
| Parassintética | Entram os dois **ao mesmo tempo**: sem um deles a palavra não existe | **en**tard**ecer** |
| Regressiva | A palavra **perde** parte da terminação | buscar → busca |
| Imprópria | Muda só a classe gramatical; a forma fica igual | **o** jantar, **o** talvez |

> [!danger] ✍️ Seu erro de 24/09
> "Desnome" (Manoel de Barros) ficou em branco. É **derivação prefixal**: des- + nome, como *desumano* e
> *desconforto*. Não é parassíntese, porque não tem sufixo nenhum.

### 3.1 Parassíntese × prefixal e sufixal

Os dois têm prefixo e sufixo. A diferença está em **como** eles entraram na palavra.

- **Parassíntese:** prefixo e sufixo entram **juntos, num só movimento**. Por isso não dá para tirar só
  um deles: a sobra não existe em português.
- **Prefixal e sufixal:** os afixos entraram **um de cada vez**. Tirando só um, a sobra é uma palavra
  que existe.

**O teste das duas sobras:** tire só o prefixo e veja se a sobra existe; depois tire só o sufixo e veja
de novo.

| Palavra | Sem o prefixo | Sem o sufixo | Conclusão |
|---|---|---|---|
| entardecer | *tardecer* ✗ | *entarde* ✗ | parassíntese |
| anoitecer | *noitecer* ✗ | *anoite* ✗ | parassíntese |
| entristecer | *tristecer* ✗ | *entriste* ✗ | parassíntese |
| enraizar | *raizar* ✗ | *enraiz* ✗ | parassíntese |
| subterrâneo | *terrâneo* ✗ | *subterra* ✗ | parassíntese |
| deslealdade | lealdade ✓ | desleal ✓ | prefixal e sufixal |
| infelizmente | felizmente ✓ | infeliz ✓ | prefixal e sufixal |
| desigualdade | igualdade ✓ | desigual ✓ | prefixal e sufixal |

A maioria dos parassintéticos é **verbo** que começa com *a-* ou *en-* e termina em *-ecer* ou *-ar*.

> `2026.1-OBJ-27` pediu para identificar o **verbo** formado por parassíntese.

### 3.2 Derivação regressiva

> [!abstract] Definição
> Na **derivação regressiva** a palavra nova é **menor** que a primitiva. O caso que cai: o **verbo
> perde a terminação** (-ar, -er, -ir) e vira **substantivo**, que ganha uma vogal final *-a*, *-o* ou
> *-e*. O substantivo formado assim se chama **deverbal** ("que vem do verbo").

| Verbo | Deverbal |
|---|---|
| buscar | a busca |
| recuar | o recuo |
| atacar | o ataque |
| combater | o combate |
| pescar | a pesca |
| chorar | o choro |
| sacar | o saque |
| castigar | o castigo |
| debater | o debate |
| embarcar | o embarque |

Todos esses substantivos têm uma coisa em comum: **nomeiam uma ação**. *A busca* é o ato de buscar;
*o ataque*, o ato de atacar.

**A pegadinha: quem veio primeiro?** Nem todo par de verbo e substantivo parecidos é regressivo. Às
vezes o substantivo é o primitivo, e o **verbo** é que foi formado dele, com o sufixo *-ar*. O critério
é a **ação**:

- Substantivo que nomeia **ação** → veio do verbo → **derivação regressiva** (buscar → a busca).
- Substantivo que nomeia **coisa, objeto ou substância** → é primitivo; o verbo deriva dele por
  **derivação sufixal** (perfume → perfumar).

**Teste:** troque o substantivo por "o ato de ___". *A busca* = o ato de buscar: funciona, então é
regressiva. *O perfume* = o ato de perfumar: não funciona, porque perfume é uma coisa. Ele veio primeiro.

| Primitivo (coisa) | Derivado por sufixo (verbo) |
|---|---|
| perfume | perfumar |
| planta | plantar |
| âncora | ancorar |
| escova | escovar |
| martelo | martelar |
| telefone | telefonar |
| vacina | vacinar |

> [!warning] ⚠️ Ajuste à aula: a seta está invertida
> A anotação diz "perfumar → perfume: derivação sufixal". O caminho é o contrário: **perfume → perfumar**.
> A palavra derivada é o verbo *perfumar* (perfume + -ar), e é ele que se forma por derivação sufixal.
> *Perfume* é primitiva. O mesmo vale para planta → plantar.

> [!danger] ✍️ Seu erro de 23/09 (nota 25%)
> "Vacina é derivação regressiva?" Você respondeu que não, mas sem citar o verbo nem o critério.
> A resposta completa: "Não. *Vacina* nomeia uma substância, não uma ação; é palavra primitiva. É o verbo
> *vacinar* que deriva dela, por sufixação (vacina + -ar). Regressiva é o caminho contrário, como em
> combater → o combate."

### 3.3 Derivação imprópria (conversão)

> [!abstract] Definição
> Na **derivação imprópria**, também chamada **conversão**, a palavra **muda de classe gramatical sem
> mudar de forma**. Nada é acrescentado nem tirado: o que muda é o **contexto**. Por isso ela só pode ser
> identificada dentro da frase.

A marca mais comum é o **artigo** (ou outro determinante: *este*, *um*, *meu*) na frente de uma palavra
que não é substantivo. O artigo "carimba" a palavra como substantivo.

| De → para | Exemplos |
|---|---|
| advérbio → substantivo | "**O talvez** é melhor." · "**os longes**" (exemplo da aula, citado como de Drummond) · "Ela disse **um não** firme." |
| verbo → substantivo | "**O jantar** esfriou." · "**O olhar** dela dizia tudo." |
| adjetivo → substantivo | "**O belo** nem sempre é útil." · ⭐ "**o mirabolante**" (`2023.1-OBJ-IL30`) |
| conjunção → substantivo | "Não entendi **o porquê**." · "Ele põe **um senão** em tudo." |
| substantivo → adjetivo | "produtos **piratas**" |
| nome próprio → comum | "Ele é **um judas**" (traidor) · **gilete** (da marca Gillette) |
| nome comum → próprio | sobrenomes como **Pereira**, **Oliveira**, **Coelho** |
| particípio → preposição | **durante**, **mediante**, **exceto**, **salvo** |
| verbo ou adjetivo → interjeição | **Viva!** · **Bravo!** · **Basta!** |

**Por que "os longes" é um exemplo tão bom:** advérbio é palavra **invariável**, nunca vai para o plural.
Quando *longe* aparece com artigo **e** com -s, as duas marcas provam que ele virou substantivo.

> [!warning] ⚠️ Ajuste à aula: "Estudar é bom"
> A aula usou a frase como exemplo de verbo funcionando como substantivo. É verdade que *estudar* ocupa o
> lugar do sujeito, mas, na análise sintática, ele continua sendo verbo: é o núcleo de uma **oração
> subordinada substantiva subjetiva reduzida de infinitivo**. A prova é que aceita advérbio, coisa de
> verbo: "Estudar **muito** é bom". A conversão fica indiscutível quando entra um determinante e um
> adjetivo: "**O** estudar **constante** cansa". Numa alternativa, prefira o exemplo com artigo.

**Imprópria × regressiva:** em "o jantar" (imprópria), o verbo *jantar* aparece inteiro, só ganhou artigo.
Em "a pesca" (regressiva), o verbo *pescar* perdeu o *-r* e encolheu. Na imprópria a forma é idêntica;
na regressiva, a palavra diminui.

## 4. Estrangeirismos: a história dentro das palavras

> [!abstract] Definição
> **Empréstimo linguístico** é a palavra que uma língua toma de outra. **Estrangeirismo** é o nome desse
> empréstimo, sobretudo enquanto ele ainda soa estrangeiro. A aula chamou o fenômeno de **contaminação
> cultural**: quem domina a economia, a tecnologia ou o prestígio cultural de uma época exporta palavras.

### 4.1 Três formas de entrar

| Forma | O que é | Exemplos |
|---|---|---|
| **Sem adaptação** | A palavra entra com a grafia e a pronúncia originais | site, link, bullying, delivery, show, marketing |
| **Aportuguesada** | A palavra é adaptada à grafia e à pronúncia do português | futebol (*football*), bife (*beef*), sanduíche (*sandwich*), estresse (*stress*), xampu (*shampoo*), abajur (*abat-jour*) |
| **Decalque** | A expressão é traduzida ao pé da letra | arranha-céu (*skyscraper*), cachorro-quente (*hot dog*), fim de semana (*weekend*), alta-costura (*haute couture*) |

O caminho costuma ser este: a palavra entra crua, se populariza e acaba aportuguesada (*football* →
*futebol*). Quando se instala, ganha sufixos do português: *deletar*, *printar*, *tuitar* são verbos em
-ar feitos com raiz inglesa.

### 4.2 Cada época, uma língua

| Influência | Quando e por quê | Exemplos |
|---|---|---|
| **Anglicismos** (inglês) | Desde o pós-guerra (anos 1950): o poderio econômico e tecnológico dos EUA, com cinema, música, publicidade, informática e internet | futebol, bife, sanduíche; site, link, bullying, e-mail, marketing |
| **Galicismos** (francês) | Até os anos 1950 o francês era a língua de prestígio (moda, culinária, arte, diplomacia) e a segunda língua ensinada nas escolas | batom (*bâton*), perfume, maionese, abajur, garçom, chique, buquê, crochê, restaurante |
| **Africanismos** | Mais de três séculos de escravidão, até 1888; sobretudo línguas bantas (quimbundo, quicongo) e o iorubá | tutu, candomblé, macumba, samba, caçula, cafuné, moleque, quitanda, fubá, quiabo, dendê, acarajé, berimbau, senzala, quilombo |
| Italiano | Imigração (fim do século XIX e começo do XX), culinária e música | pizza, lasanha, espaguete, tchau (*ciao*), maestro |
| Japonês | Imigração (a partir de 1908) e cultura pop | sushi, tempurá, saquê, quimono, judô, karaokê, mangá |
| Russo | Culinária e política | vodca, estrogonofe, czar |

> [!warning] ⚠️ Ajustes à aula (africanismos)
> **Datas:** a aula deu 1510–1888. O fim é certo (1888, Lei Áurea). O começo varia entre os
> historiadores, e a maioria situa o início do tráfico regular para o Brasil entre 1530 e 1550. Para a
> prova, basta: **mais de três séculos de escravidão**.
> **Feijoada:** a palavra é portuguesa (feijão + -ada, derivação sufixal). O prato pode estar ligado à
> cultura afro-brasileira, mas a palavra não vem de língua africana. Se a questão for sobre a **origem
> da palavra**, use samba, cafuné, caçula ou moleque.

**Além da aula, vale saber:** as duas influências mais antigas e maiores.
- **Árabe:** quase oito séculos de domínio muçulmano na Península Ibérica (de 711 a 1492). Muitas
  começam com *al-*, o artigo árabe: açúcar, algodão, alface, almofada, azeite, arroz, alfândega,
  álgebra, xadrez, oxalá.
- **Tupi:** a língua de quem já estava aqui. Sobretudo fauna, flora e lugares: mandioca, pipoca,
  capivara, jabuticaba, jacaré, peteca, cutucar, Ipanema, Paraná.

### 4.3 Estrangeirismo na sua escrita

A gramática normativa trata o estrangeirismo **desnecessário** como vício de linguagem: usar *delivery*
quando existe *entrega*. Na redação e nas dissertativas:
- se existe equivalente em português, use o português;
- se não existe, ou se o termo técnico é o estrangeiro, use a palavra **entre aspas** (à mão não há
  itálico).

Todo empréstimo novo é, também, um **neologismo** (seção 6).

## 5. Siglas e abreviações (siglonímia)

> [!abstract] Definição
> **Siglonímia** é a formação de palavras a partir das **letras ou sílabas iniciais** de uma expressão
> longa. O motivo é a **economia comunicativa**: dizer mais com menos. *Organização das Nações Unidas*
> vira **ONU**.

| Tipo | Como se lê | Exemplos |
|---|---|---|
| Sigla soletrada | letra por letra | FMI, FGV, STF, INSS, BNDES |
| Acrônimo | como uma palavra | ONU, OTAN, Unicamp, Embrapa |

**OTAN × NATO:** são a mesma organização. OTAN é a sigla em português (**O**rganização do **T**ratado do
**A**tlântico **N**orte); NATO, em inglês (**N**orth **A**tlantic **T**reaty **O**rganization). A ordem
das letras muda porque, em inglês, o adjetivo vem antes do substantivo.

**Como escrever** (convenção dos manuais de redação):
- até três letras: tudo maiúsculo (ONU, FMI, STF);
- quatro letras ou mais, lidas como palavra: só a inicial maiúscula (Unicamp, Embrapa);
- lidas letra por letra: tudo maiúsculo, de qualquer tamanho (INSS, BNDES);
- plural: *s* minúsculo, sem apóstrofo (as ONGs, os CDs).

**A sigla vira palavra de verdade:** ganha sufixos e forma derivados. PT → *petista*, CLT → *celetista*,
PMDB → *peemedebista*, USP → *uspiano*. É derivação sufixal feita em cima de uma sigla.

| Recurso | O que é | Exemplos |
|---|---|---|
| **Sigla** | Iniciais de uma expressão | ONU, FGV |
| **Abreviação vocabular** | Corte de uma palavra longa, que passa a ser dita assim também na fala | foto (fotografia), moto (motocicleta), metrô (metropolitano), pneu (pneumático), cinema (cinematógrafo) |
| **Abreviatura** | Redução só na escrita, quase sempre com ponto; na leitura, diz-se a palavra inteira | Dr., Sra., pág., V. Exa. |

## 6. Neologismos

> [!abstract] Definição
> **Neologismo** é uma palavra nova, ou um **sentido novo** para uma palavra que já existia, que entra na
> língua para nomear algo que ainda não tinha nome: uma tecnologia, um costume, um fato político.
> O oposto é o **arcaísmo**, a palavra que saiu de uso.

### 6.1 Dois tipos

- **Neologismo formal (ou vocabular):** nasce uma palavra que não existia. Ela é formada pelos processos
  que você já estudou: derivação (*mensalão*), composição, empréstimo (*podcast*), sigla.
- **Neologismo semântico:** a palavra já existia e ganha um sentido novo. *Laranja* (da fruta à pessoa
  que empresta o nome), *nuvem* (onde se guardam arquivos), *vírus* (de computador), *navegar* (na
  internet), *cancelar* (alguém nas redes).

### 6.2 Os neologismos políticos da aula

| Palavra | O que nomeia | Como se formou | Tipo |
|---|---|---|---|
| **Mensalão** | Pagamentos mensais a parlamentares em troca de votos no Congresso, revelados em 2005, no primeiro governo Lula | mensal + -ão | formal, por derivação sufixal |
| **Petrolão** | Desvio de dinheiro da Petrobras, com contratos superfaturados e propina, investigado pela Operação Lava Jato a partir de 2014 | petról(eo) + -ão, por **analogia** com *mensalão* | formal, por derivação sufixal e analogia |
| **Laranja** | Pessoa que empresta o nome (conta, empresa, bens) para esconder o verdadeiro dono do dinheiro | palavra antiga (a fruta) com sentido novo | semântico |
| **Rachadinha** | O parlamentar fica com parte do salário do funcionário que nomeou para o gabinete | de *rachar* (dividir), com o diminutivo *-inha* | formal, por derivação sufixal |

> [!warning] ⚠️ Ajustes à aula
> **Mensalão:** a "compra de votos" era de **votos de parlamentares** no Congresso (apoio aos projetos do
> governo), não de eleitores.
> **Rachadinha:** não é só de deputado. Qualquer parlamentar que nomeia assessores pode praticá-la
> (vereador, deputado, senador).

**O que o sufixo diz:** o aumentativo **-ão** (mensalão, petrolão) marca o tamanho do escândalo e virou
quase um "sufixo de escândalo". O diminutivo **-inha** (rachadinha) dá um tom de coisa pequena e
informal, o que é irônico diante de um desvio de dinheiro público. Isso é **efeito de sentido** do
sufixo, o assunto que cai em toda prova de Português da FGV.

### 6.3 Neologismo na literatura

Escritores criam palavras de propósito, como recurso de estilo. No Brasil, os mais famosos por isso são
**Guimarães Rosa** e **Manoel de Barros**. Numa questão, o ponto costuma estar em mostrar que o autor
**pratica** aquilo que descreve: um texto sobre inventar palavras que inventa palavras. Isso é
**metalinguagem**.

## 7. Pontuação: a base da vírgula

### 7.1 Por que a pontuação existe

Na fala, organizamos o sentido com a voz: pausas, subida e descida da entonação, ritmo, ênfase, até o
gesto. A escrita não tem voz, e a pontuação existe para **compensar** essa perda. As gramáticas
tradicionais (como a de Celso Cunha e Lindley Cintra) dividem os sinais em dois grupos:

| Grupo | Sinais | O que marcam |
|---|---|---|
| **Sinais de pausa** | vírgula (pausa breve), ponto e vírgula (pausa média), ponto (pausa final) | onde a frase se divide ou termina |
| **Sinais de melodia** | dois-pontos, interrogação, exclamação, aspas, reticências, parênteses, travessão | a entonação: anúncio, pergunta, emoção, citação, suspensão, comentário |

> [!warning] ⚠️ Ajuste à aula
> A aula listou quatro sinais de melodia (dois-pontos, interrogação, exclamação e aspas). O grupo inclui
> também reticências, parênteses, travessão e colchetes.

> [!info] A pausa explica a origem, mas não é a regra
> Não se põe vírgula "onde se respira". Muitas pausas da fala não levam vírgula (depois de um sujeito
> longo, por exemplo), e muitas vírgulas não correspondem a pausa nenhuma. **A vírgula é decidida pela
> sintaxe**, pela ordem dos termos na frase. É isso que as próximas seções mostram.

### 7.2 A regra base: a ordem direta não tem vírgula

A ordem direta da oração em português é:

**sujeito → verbo → complementos → adjuntos adverbiais**

"**Laura** / **entregou** / **a redação** / **ao professor** / **ontem**."

Com os termos nessa ordem, **não se usa vírgula entre eles**. Termos que se ligam diretamente nunca são
separados:

- ✗ Sujeito e verbo: "Os alunos que estudaram durante o ano inteiro**,** passaram." Sujeito longo
  continua sendo sujeito. O certo é sem vírgula.
- ✗ Verbo e complemento: "O professor entregou**,** as provas corrigidas."
- ✗ Nome e complemento: "A necessidade**,** de estudo."

> [!warning] ⚠️ Ajuste à aula: o "nunca" tem uma exceção que não quebra a regra
> A enumeração leva vírgula mesmo na ordem direta: "Laura estuda português**,** história e matemática."
> Aqui a vírgula não separa termos de funções diferentes; separa itens da **mesma** função (três objetos
> diretos). A regra da aula vale para termos de funções diferentes.

> [!info] Pegadinha: inverter sujeito e verbo não pede vírgula
> "Chegaram**,** os resultados" está errado. O sujeito posposto (depois do verbo) continua ligado a ele:
> "Chegaram os resultados." A inversão que pede vírgula é a do **adjunto adverbial**, não a do sujeito.
> ⭐ A FGV pediu duas vezes para reconhecer sujeito posposto: `2024.1-OBJ-27` e `2026.1-OBJ-20`.

### 7.3 Caso 1: inversão

Quando um termo sai do seu lugar na ordem direta e vai para a frente, a vírgula marca o deslocamento.
O caso mais comum é o **adjunto adverbial** (tempo, lugar, modo, causa) que vai para o começo da frase.

- Ordem direta: "Laura revisou a matéria durante as férias de julho." (sem vírgula)
- Invertida: "**Durante as férias de julho,** Laura revisou a matéria."

Na prática:
- **Adjunto adverbial longo** no início: vírgula.
- **Adjunto adverbial curto** no início: vírgula **facultativa**. "Ontem(,) Laura revisou a matéria."
- **Oração adverbial** no início: vírgula. "Quando a aula acabou, Laura foi para casa." No fim da frase,
  a vírgula fica facultativa: "Laura foi para casa quando a aula acabou."

A próxima aula (colocação do advérbio) aprofunda este caso.

> [!danger] ✍️ Seu erro de 23/09
> "Sob essa perspectiva a palavra vacina não corresponde…" → "Sob essa perspectiva**,** a palavra…".
> Expressão deslocada para o início da frase fica melhor separada por vírgula. Na correção era só
> recomendação, mas é esse o hábito a criar.

### 7.4 Caso 2: inserção (intercalação)

Quando um elemento **explicativo** ou **adverbial** entra no meio da ordem direta, interrompendo-a, ele
fica **entre vírgulas**. São sempre **duas**: uma abre, a outra fecha.

| O que se intercala | Exemplo |
|---|---|
| Aposto explicativo | "Laura**,** aluna da EABH**,** vai prestar FGV." |
| Adjunto adverbial no meio | "Laura**,** ontem**,** revisou a matéria." |
| Conjunção deslocada | "A prova**,** porém**,** foi adiada." · "Ela**,** portanto**,** precisa revisar." |
| Expressão explicativa (*isto é*, *ou seja*, *por exemplo*, *aliás*) | "Faltam 19 dias**,** ou seja**,** menos de três semanas." |
| Oração intercalada | "A prova**,** disse o professor**,** vai ser difícil." |
| Vocativo (chamamento) ⭐ | "Laura**,** venha cá." · "Venha cá**,** Laura." |
| Oração adjetiva explicativa ⭐ | ver abaixo |

> [!info] Erro clássico: abrir e não fechar
> "Laura, aluna da EABH vai prestar FGV." Faltou a segunda vírgula, e o aposto "vazou" para dentro da
> frase.

**Oração adjetiva: explicativa × restritiva ⭐**

Não estava na aula, mas foi **exatamente o que a FGV cobrou** nas duas questões de vírgula do banco
(`2023.1-DIS-LP13` e `2025.1-OBJ-17`). É um caso de inserção.

- **Explicativa:** acrescenta uma informação sobre **todo** o grupo, ou sobre um ser único. Vai **entre
  vírgulas**. "Os alunos**,** que estudaram**,** foram aprovados." → todos os alunos estudaram, e todos
  foram aprovados.
- **Restritiva:** **limita** o grupo, separa uma parte dele. Vai **sem vírgula**. "Os alunos que
  estudaram foram aprovados." → só os que estudaram foram aprovados; houve quem não estudou.
- **Ser único** (nome próprio, *o Brasil*, *minha mãe*): a oração é sempre explicativa. "Machado de
  Assis**,** que foi o primeiro presidente da Academia Brasileira de Letras**,** escreveu *Dom Casmurro*."

**Teste:** tire a oração. Se a frase continua falando do mesmo grupo inteiro, ela era explicativa (com
vírgulas). Se o grupo "cresce" (antes eram só alguns, agora são todos), ela era restritiva (sem
vírgula). A vírgula muda o sentido, e é isso que a FGV explora: a dissertativa de 2023.1 pedia qual
oração com "que" deveria ter vírgula.

### 7.5 Vírgula antes do "e"

Regra geral: o "e" já liga as orações, então não se usa vírgula antes dele. "Laura estudou e dormiu."
(mesmo sujeito)

Usa-se vírgula antes do "e":
1. **Quando os sujeitos das orações são diferentes:** "Laura estudou português**, e** a irmã assistiu à
   aula de física."
2. **Quando o "e" tem valor de "mas"** (adversativo): "Estudou a noite inteira**, e** não passou."
3. **Quando o "e" se repete** para dar ênfase (polissíndeto): "E ri**, e** chora**, e** grita."

> [!warning] ⚠️ Ajuste à aula: "obrigatória"
> A aula disse que, com sujeitos diferentes, a vírgula é obrigatória. Nas gramáticas, a regra aparece
> como recomendação ("costuma-se usar"), e alguns autores a dispensam em orações curtas. Na prática:
> **na sua redação, use sempre** (nunca vai contar como erro); **numa alternativa**, não descarte uma
> frase só porque ela não tem essa vírgula.

**Outras conjunções (além da aula):** *mas*, *porém* e o *pois* explicativo também vêm depois de
vírgula, porque ligam orações coordenadas. "Ela não é regressiva**, pois** é primitiva."

> [!danger] ✍️ Vírgula antes de "pois": duas vezes
> Faltou na correção de Artes e na questão da "vacina". "…não corresponde a uma derivação regressiva**,
> pois** é uma palavra primitiva."

### 7.6 Zeugma: a vírgula no lugar do verbo

> [!abstract] Definição
> **Zeugma** é a omissão de um termo que **já apareceu** antes na frase, geralmente o verbo. Na escrita,
> a vírgula marca o lugar vazio.

- "Eu prefiro café; ela**,** chá." → a vírgula está no lugar de *prefere*.
- "Laura estuda de manhã; a irmã**,** à noite." → no lugar de *estuda*.

Repare no ponto e vírgula entre as duas orações: ele é comum no zeugma, porque a vírgula já está sendo
usada dentro da segunda oração.

**Zeugma × elipse:** as duas são omissões (figuras de sintaxe). Na **elipse**, o termo omitido **não
apareceu antes**; você o recupera pelo contexto ou pela terminação do verbo: "Estudamos ontem" (*nós*
está implícito). No **zeugma**, o termo omitido **já foi dito** na frase. Todo zeugma é um tipo de
elipse; nem toda elipse é zeugma.

### 7.7 A vírgula num quadro só

| Situação | Vírgula? | Exemplo |
|---|---|---|
| Sujeito e verbo, mesmo com sujeito longo | Não | Os alunos que estudaram passaram. |
| Verbo e complemento | Não | Laura entregou a redação. |
| Sujeito posposto | Não | Chegaram os resultados. |
| Enumeração | Sim | português, história e matemática |
| Adjunto adverbial longo no início | Sim | Durante as férias, Laura revisou. |
| Adjunto adverbial curto no início | Facultativa | Ontem(,) Laura revisou. |
| Oração adverbial no início | Sim | Quando a aula acabou, saiu. |
| Aposto, vocativo, expressão explicativa, conjunção deslocada | Sim, entre duas | Laura, aluna da EABH, vai prestar FGV. |
| Oração adjetiva explicativa ⭐ | Sim, entre duas | Os alunos, que estudaram, passaram. |
| Oração adjetiva restritiva ⭐ | Não | Os alunos que estudaram passaram. |
| "e" com o mesmo sujeito | Não | Estudou e dormiu. |
| "e" com sujeitos diferentes | Sim (recomendada) | Laura estudou, e a irmã dormiu. |
| *mas*, *pois* explicativo | Sim | …regressiva, pois é primitiva. |
| Verbo omitido (zeugma) | Sim | Eu prefiro café; ela, chá. |

## 8. Para não confundir

| Par | Como separar |
|---|---|
| Regressiva × sufixal | Substantivo de ação veio do verbo (buscar → busca). Substantivo de coisa veio antes, e o verbo deriva dele (perfume → perfumar). |
| Parassíntese × prefixal e sufixal | Tire um afixo de cada vez. Nenhuma sobra existe → parassíntese. Alguma existe → prefixal e sufixal. |
| Imprópria × regressiva | Imprópria: mesma forma, nova classe (o jantar). Regressiva: a palavra encolhe (pescar → pesca). |
| Justaposição × aglutinação | As partes voltam inteiras (girassol) × alguma perdeu som (planalto). |
| Erudita × híbrida | Radicais da mesma língua clássica (democracia) × de línguas diferentes (automóvel). |
| Sem adaptação × aportuguesado × decalque | site × futebol × arranha-céu |
| Sigla × abreviação × abreviatura | ONU × foto × Dr. |
| Neologismo formal × semântico | Palavra nova (mensalão) × sentido novo (laranja) |
| Zeugma × elipse | Omite o que já foi dito × omite o que se subentende |
| Explicativa × restritiva | Com vírgulas, vale para todos × sem vírgulas, só para alguns |
